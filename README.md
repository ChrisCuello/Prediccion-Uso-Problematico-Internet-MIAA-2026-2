## Descripción del proyecto

El proyecto tiene como propósito estudiar el uso problemático de internet en niños y adolescentes mediante técnicas de ciencia de datos y aprendizaje automático.

Se fundamenta en la competición **Child Mind Institute — Problematic Internet Use**, publicada en Kaggle, que propone predecir los niveles de severidad del uso problemático de internet utilizando información de actividad física, características demográficas y otras mediciones de los participantes del estudio Healthy Brain Network.

## Planteamiento del problema

El uso problemático de internet en niños y adolescentes constituye un desafío para la salud y el bienestar. Su identificación mediante métodos convencionales puede presentar barreras relacionadas con el acceso a instrumentos especializados y la necesidad de evaluación profesional.

Ante esta situación, se plantea explorar el potencial del aprendizaje automático para identificar patrones en variables físicas, demográficas y conductuales que permitan predecir diferentes niveles de severidad del uso problemático de internet.

## Objetivo general preliminar

Desarrollar y evaluar un modelo de aprendizaje automático para predecir los niveles de severidad del uso problemático de internet en niños y adolescentes utilizando datos del estudio Healthy Brain Network.

## Fuente de datos

**Competición:** Child Mind Institute — Problematic Internet Use.

**Plataforma:** Kaggle.

**Variable objetivo:** Severity Impairment Index (`sii`).

La variable objetivo contempla cuatro categorías:

- 0: Ninguno.
- 1: Leve.
- 2: Moderado.
- 3: Severo.
